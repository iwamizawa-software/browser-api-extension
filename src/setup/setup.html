音声データの送信について

  • SpeechRecognition を置き換えたサイトで認識が開始されると、マイク音声（発話区間のみ）は ページの内容に関わらず Groq (api.groq.com) に送信されます。
  • 音声認識を許可するサイトは manifest.json にだけ書かれています（下の「3. 設定」に表示）。 そこに書かれたサイトは、ブラウザの通常のマイク許可プロンプトなしでマイクを使い、文字起こし結果を受け取れます。 信頼できるサイトだけを書いてください。
  • マイク使用中は拡張機能アイコンに MIC が表示されます。
  • API キーは拡張機能内部 (chrome.storage.local) にのみ保存され、Web ページには渡されません。
